How it works

Ten seconds, before you send money, documents, or personal numbers.

Bring the message in. Paste text, import a screenshot, use the share sheet from Mail or Messages, or run the "Check this with SecondLook" Shortcut.

Pick your hiring stage — first contact, interviewing, offer, or onboarding — or leave it as "not sure."

Read the report. An overall read plus an itemized list of what's unusual, each with a plain-language reason and a next step.

Optionally, go deeper. "Deep AI Check" sends the screenshot and text to an AI model for a closer read — only when you tap it, after a one-time explanation.
